# Лабораторная работа №1 — Страница-визитка

**Автор:** Трофимов Михаил Олегович, группа ФИТ-241

## Описание

Одностраничный адаптивный сайт-визитка, сверстанный на чистом HTML и CSS.
Страница содержит семантические разделы Header, About, Skills, Portfolio,
Contacts и Footer с переходами по якорям, а раскладка построена на Flexbox
и CSS Grid. Реализованы три брейкпоинта: mobile (≤767px), tablet
(768–1023px) и desktop (≥1024px).
