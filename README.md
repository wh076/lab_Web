# Трофимов Михаил Олегович ФИТ-241

## Лабораторная работа №10 — Архитектура и расширение To-Do

Личный список задач на Vue 3, TypeScript, Pinia и Vue Router. У задач можно указать начало, дедлайн, приоритет и метки. Авторизация учебная, используйте вымышленные email и пароли.

Ссылка на приложение: <https://wh076.github.io/lab_Web/lab10/>

## Команды

Проверено на Node.js v24.13.0.

```bash
npm ci
npm run dev
npm run type-check
npm run lint
npm run format:check
npm run lint:fix
npm run format
npm run check
npm run build
npm run preview
```

`check` проверяет типы, правила ESLint и форматирование. `build` выполняет те же проверки перед сборкой Vite.

## Устройство приложения

- **Domain** описывает задачу и задаёт правила проверки, сортировки, поиска и календарного отбора.
- **Application** выполняет загрузку, добавление, редактирование, отметку и удаление через контракт `TodoRepository`. Идентификатор пользователя передаёт Pinia.
- **Infrastructure** реализует контракт для localStorage и для памяти. Оба адаптера разделяют списки пользователей. В памяти задачи живут до перезагрузки.
- **Presentation** содержит страницы, компоненты и Pinia. Они управляют формой, вкладками, состоянием и отображением ошибок.

Presentation вызывает Application, которая использует Domain и контракт репозитория. Infrastructure реализует этот контракт. Адаптер localStorage подключён в `src/setup/todo.ts`. Там же передаётся функция создания идентификатора.

## Задачи и данные

Даты вводятся в местном времени и хранятся в ISO 8601 в UTC. При открытии формы они снова показываются в местном времени. Начало и дедлайн независимы. Если указаны оба, дедлайн может совпадать с началом или быть позже.

Сначала идут открытые задачи, затем выполненные. В каждой группе порядок определяется убыванием приоритета, затем более ранним дедлайном и более ранним началом. При прочих равных задача без соответствующей даты идёт после задачи с этой датой.

- **Поиск** показывает открытые задачи и применяет оба фильтра — название и метку.
- **Все** показывает задачи пользователя, включая выполненные.
- **На сегодня** отбирает по дедлайну за текущий местный день.
- **Грядущие** отбирают по дедлайну с понедельника по воскресенье текущей недели, включая прошедшие дни. В обеих календарных вкладках выполненные включаются отдельными чекбоксами.
- **Выполненные** показывает завершённые задачи независимо от дат.

Репозиторий при первом чтении проверяет записи из `lab7-tasks` и переносит их в `lab10-tasks` с прежними ID, владельцами и отметками. Начало и дедлайн остаются пустыми, приоритет равен 0, меток нет. Затем используется новый ключ, в том числе при пустом списке. Старый ключ сохраняется для №7 и №9. Для авторизации и темы по-прежнему используются `lab7-user` и `theme`.

При push в `lab10` GitHub Actions собирает версии из их веток и публикует [общий указатель](https://wh076.github.io/lab_Web/) и отдельные каталоги одним артефактом. Окружению `github-pages` требуется разрешить публикацию только из `lab10`.
