# Трофимов Михаил Олегович ФИТ-241

## Хэллоуинский проект. «Тёмный дом»

Мини-игра «найди призраков с фонариком». Экран почти полностью тёмный, видно только круг света вокруг курсора (на телефоне — вокруг пальца). В комнатах прячутся призраки, тыквы, пауки и летучие мыши. Призраки — это хвосты по учёбе: по клику призрак исчезает, и всплывает подпись вроде «Матан изгнан». Если навести на призрака фонарик слишком быстро, он может испугаться и убежать.

Что есть:
- стартовый экран с кнопкой «Войти в дом» и финальный экран с результатом и кнопкой «Ещё раз»;
- 3 комнаты (Прихожая, Библиотека, Чердак) с разным фоном и количеством призраков (3, 5, 7);
- таймер, счётчик найденных, лучшее время по комнатам и за всю игру в localStorage;
- звуки через Web Audio API без звуковых файлов, кнопка вкл/выкл (по умолчанию выключен);
- смешной скример в конце комнаты (тыква подпрыгивает и кричит «Бу!»), его можно отключить;
- падающие листья и паутина на фоне, шрифт Rubik Wet Paint из Google Fonts для заголовков;
- адаптивность от 320px, управление пальцем, учёт `prefers-reduced-motion`;
- кнопки — `<button>` с `aria-label`, видимый фокус, игра проходится с клавиатуры (Tab и Enter, фонарик переезжает к призраку в фокусе).

## Что использовано

- Vue 3 (Composition API, `<script setup>`, однофайловые компоненты);
- Vite;
- Sass (структура `base`, `components`, `layout`, `utils`, `themes`);
- все персонажи нарисованы в SVG прямо в компонентах (`src/components/creatures`);
- фонарик — слой с `radial-gradient`, который двигается через `transform`.

## Как запустить

```bash
npm install
npm run dev
```

Сборка: `npm run build`, просмотр собранной версии: `npm run preview`.
