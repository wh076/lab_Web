# Трофимов Михаил Олегович ФИТ-241

## Лабораторная работа №9. Перенос To-Do на TypeScript. ESLint и Prettier

To-Do из лабораторной №7 на Vue 3, Pinia и Vue Router. Можно зарегистрироваться, войти, добавлять, редактировать, удалять, искать и отмечать задачи. У каждого пользователя свой список. Задачи, пользователи и выбранная тема сохраняются в localStorage.

Ссылка на приложение: <https://wh076.github.io/lab_Web/>

## Команды

Проверено на Node.js v24.13.0.

```bash
npm ci
npm run dev
npm run type-check
npm run lint
npm run format:check
npm run lint:fix
npm run format
npm run check
npm run build
npm run preview
```

`npm run check` проверяет типы, правила ESLint и форматирование. `npm run build` сначала запускает эти проверки и только после их успеха собирает проект в `dist`. `vue-tsc` проверяет типы в коде приложения и шаблонах Vue, а `tsc` проверяет конфигурацию Vite. Vite преобразует исходники и собирает файлы для публикации. `npm run preview` запускает локальный просмотр сборки. `lint:fix` исправляет правила, для которых у ESLint есть автоматическое исправление, а `format` переформатирует файлы.

## Порядок проверки

Авторизация учебная, данные хранятся в браузере. Используйте вымышленные email и пароли, например `student1@example.test` и `Study-123`.

1. Зарегистрировать первого пользователя, войти и добавить пару задач. Отредактировать одну, отметить выполненной и найти её по названию.
2. Обновить страницу задач. Аккаунт, задачи и отметка выполнения должны восстановиться.
3. Выйти и открыть `/lab_Web/#/todo` гостем. Должна открыться страница входа.
4. Зарегистрировать второго пользователя с другим вымышленным email, войти и проверить, что задач первого пользователя нет.
5. Выйти и снова войти первым пользователем. Его задачи должны появиться снова. Страница «О приложении» доступна и после выхода.
