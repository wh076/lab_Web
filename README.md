# Сайт-визитка — Лабораторная работа №3 (Sass)

**Автор:** Трофимов Михаил Олегович, группа ФИТ-241

## Описание

Личная страница-визитка из лабораторных №1–2: адаптивная вёрстка
(mobile / tablet / desktop) и интерактив на **jQuery** — выпадающее меню,
подсветка активного пункта, модальное окно с формой и валидацией,
отправка через `$.ajax()`, карусель портфолио из `data/portfolio.json`,
кнопка «Вверх».

В третьей лабораторной стили переписаны на препроцессоре **Sass (SCSS)**:

- стили разбиты на модули (`utils`, `base`, `layout`, `components`, `themes`),
  подключение только через `@use` / `@forward`, в каждой папке есть `_index.scss`;
- значения вынесены в переменные, брейкпоинты и палитры тем описаны картами;
- своя функция `rem()` — перевод px в rem;
- миксины `respond-to()` (с `@content` и `@error`) и `flex-center()`;
- классы переименованы по **БЭМ**, селекторы в итоговом CSS — не длиннее 2 уровней;
  JavaScript работает через отдельные классы `js-*`, id и `data`-атрибуты;
- **светлая и тёмная темы**: палитры `$theme-light` / `$theme-dark` → CSS-переменные
  через `@each`; переключатель в шапке ставит `data-theme` на `<html>`,
  выбор сохраняется в `localStorage`, при первом визите учитывается
  системная тема (`prefers-color-scheme`);
- компонент `.button` со всеми состояниями (`:hover`, `:focus-visible`,
  `:active`, `:disabled`) и модификаторами `--primary`, `--outline`, `--small`.

## Структура проекта

```
lab_Web/
├─ scss/
│  ├─ utils/        переменные, функции, миксины
│  ├─ base/         reset, типографика
│  ├─ layout/       контейнер, шапка, навигация, секции, подвал
│  ├─ components/   кнопка, карточки, карусель, модалка, форма, «Вверх»
│  ├─ themes/       светлая и тёмная темы
│  └─ main.scss     точка входа
├─ dist/            собранный CSS (не хранится в git)
├─ js/script.js
├─ data/portfolio.json
├─ images/
├─ index.html
├─ package.json
└─ package-lock.json
```

## Запуск с нуля

Нужен [Node.js](https://nodejs.org/) (LTS).

```bash
npm install
npm run build      # однократная сжатая сборка в dist/css/main.css
# или
npm run sass:dev   # пересборка при каждом сохранении (для разработки)
```

Страницу нужно открывать через локальный сервер (из-за `$.getJSON`),
например расширением **Live Server** в VS Code или командой:

```bash
npx serve .
```

При разработке запускаются два процесса одновременно: `npm run sass:dev`
и локальный сервер.
