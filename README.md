**Автор:** Трофимов Михаил Олегович, группа ФИТ-241

## Описание

Расширение сайта-визитки из лабораторной работы №1: та же адаптивная
HTML/CSS-страница (mobile / tablet / desktop), дополненная динамическим
поведением на **jQuery** (подключена через CDN).

## Что реализовано на jQuery

- **Выпадающее меню** — на мобильной ширине кнопка «☰ Меню» показывает и
  скрывает список навигации (`toggleClass` + управление `aria-expanded`).
- **Подсветка активного пункта меню** — при скролле пункт меню, отвечающий
  текущему разделу, получает класс `.active`.
- **Кнопка «Вверх»** — появляется после прокрутки страницы и плавно
  возвращает наверх через `animate({ scrollTop: 0 })`.
- **Модальное окно** с формой обратной связи — открывается кнопкой
  «Написать мне», закрывается по крестику, клику по оверлею или клавише
  `Esc`.
- **Валидация формы** — проверяются обязательные поля (имя, сообщение) и
  формат email; ошибки выводятся под каждым полем.
- **Симуляция отправки формы через `$.ajax()`** — после успешной валидации
  данные отправляются `POST`-запросом на тестовый эндпоинт
  `jsonplaceholder.typicode.com/posts`, результат отображается статусом
  под формой.
- **Динамическая галерея портфолио** — данные о проектах загружаются из
  `data/portfolio.json` через `$.getJSON`, карточки генерируются
  jQuery-ом на лету.
- **Карусель портфолио** — та же галерея оформлена как слайдер с кнопками
  «Предыдущий» / «Следующий», кликабельными точками-индикаторами и
  автопрокруткой (пауза при наведении курсора).
- **Анимация** — карточки портфолио появляются через `fadeIn` при
  рендеринге; раскрытие мобильного меню анимировано `slideToggle`-подобным
  поведением через CSS-переход.

## Запуск

Проект статический, сборка не требуется. Из-за `$.getJSON` открывать
страницу нужно через локальный сервер (например, расширение **Live
Server** в VS Code), а не двойным кликом по файлу — иначе браузер
блокирует загрузку JSON по CORS-политике для `file://`.
