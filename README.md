# Трофимов Михаил Олегович ФИТ-241

## Лабораторная работа №7. To-Do с Pinia и Vue Router

To-Do из лабораторной №6, теперь с регистрацией и входом. У каждого пользователя свой список задач. Данные хранятся в сторах Pinia, страницы переключаются через Vue Router. Стек: Vue 3, Vite, Pinia, Vue Router, Sass.

Ссылка: https://wh076.github.io/lab_Web/

## Команды

```bash
npm ci
npm run dev
npm run build
```

## Про авторизацию

Авторизация учебная, сервера нет. Все данные, включая пароли, лежат в localStorage браузера в открытом виде. Используйте только вымышленные email и пароли.

## Порядок проверки

1. Зарегистрировать двух пользователей.
2. Войти первым и добавить задачи.
3. Выйти и войти вторым: задач первого нет.
4. Обновить страницу: данные на месте.
5. Выйти и открыть `/#/todo` гостем: происходит переход на страницу входа.
