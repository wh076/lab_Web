# Трофимов Михаил Олегович ФИТ-241

## Описание

To-Do List на Tailwind CSS и vanilla JS.

Что умеет:
- добавление задачи через модальное окно;
- редактирование и удаление задачи;
- отметка выполнения (выполненные задачи уходят вниз списка);
- поиск по названию.

Задачи сохраняются в localStorage.

## Установка

```bash
npm install
```

## Сборка

```bash
npm run build
```

## Запуск при разработке

```bash
npm run tailwind:dev
```

После этого открыть `index.html` через Live Server.
